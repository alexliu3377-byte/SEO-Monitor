读取仓库 AGENTS.md、CLAUDE.md 和 [共享审核规范](../../../docs/REVIEW_AND_RELEASE.md)。默认只读；线上指标需在用户授权范围内读取。没有指标权限时完成静态分析，说明收益未验证。

沿页面轮询/事件、API、数据库和缓存链路定位重复工作：隐藏页面、多标签、请求取消、重入、缓存键的用户/角色/日期作用域、缓存失效和降级。检查普通用户读请求是否意外承担全量统计、写缓存或批处理；缓存缺失和过期快照是否明确呈现，不能用错误数据换取低 CPU。

平台核对真实账号、项目、环境、部署 commit 和观察窗口，再记录调用数、Active CPU、错误率和超时。套餐累计用量与当前时间窗分开；排除 Demo Data。前后对比必须说明版本、时间窗、流量差异及指标定义；缺少基线不能宣称优化百分比。使用 Vercel 指标或部署工具前读取相应可用技能，不自动升级套餐、部署或变更平台配置。

数据库分析检查查询数量、分页、索引与执行路径。未经明确授权不执行生产 EXPLAIN ANALYZE、压测或全表统计；静态推断不能伪装为实际查询计划。

Windows 检查开发、Runner checkout 和浏览器/转写任务是否共用目录、依赖或 profile；关注 checkout/npm ci 与运行任务竞争、交互式登录依赖、休眠及重复进程。只读查询任务元数据，不打印含凭证的完整命令行。不停止任务或搬动运行目录；提出变更时说明维护窗口、验证与恢复路径。

输出确认问题、待测假设、证据和最小建议；明确“分支已推送”“预览部署”“正式上线”“运行副本已更新”分别是否有证据。优先级与汇总遵循 [综合审核入口](../qixin-review/SKILL.md)，无需递归执行它。自动发布文章不属于本角色。
