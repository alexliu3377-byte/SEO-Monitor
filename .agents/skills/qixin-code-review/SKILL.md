读取仓库 AGENTS.md、CLAUDE.md 和 [共享审核规范](../../../docs/REVIEW_AND_RELEASE.md)。单独调用时也先核对 git status、目标版本与范围。默认只读；用户明确指令优先，不自动扩大为生产检查或修复。

从变更入口追踪调用链和实际数据作用域：页面到接口、身份验证到资源授权、查询到响应。重点验证普通用户、管理员、超级管理员，以及公开/服务鉴权入口各自协议；不能以客户端隐藏按钮代替服务端授权。检查 service-role、RLS、RPC 权限、SECURITY DEFINER/search_path、过滤器输入、URL/SSRF 和日志泄露。Supabase 专项工作读取当前可用的 Supabase 技能。

列表检查数据库筛选、计数、排序和分页是否同一作用域；验证超过单次 REST 返回上限、空结果、重复数据和错误响应。根据改动检查异步取消、竞态、缓存跨用户泄露及失败是否冒充成功。

数据库结论只依据精确迁移和当前已获授权的结构证据。历史 schema.sql 不是完整基线；迁移存在不等于已执行。指出新旧代码兼容和恢复条件，不自动补迁移。内容删除、日期和保留期等业务规则以共享规范和实际代码为准。

测试先检查脚本是否读生产配置或有副作用，优先现有离线测试和隔离构建；不启动带生产凭证的服务做写入验证。不为审核自动更新依赖或锁文件。涉及 Next.js 行为时查已安装版本的本地文档。

报告每项问题的触发条件、位置、影响、证据、修复建议和验证方法，区分确认与待验证。另列已执行检查和未覆盖项。参考 [综合审核入口](../qixin-review/SKILL.md) 的优先级和汇总格式；单独调用无需递归执行综合审核。
