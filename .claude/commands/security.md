# 安全审核

先阅读项目根目录 AGENTS.md、CLAUDE.md 和 [共享审核与发布规范](../../docs/REVIEW_AND_RELEASE.md)。Claude 与 Codex 使用同一份规范，事实以当前代码和本次证据为准。

检查服务端用户/分组/站点授权、公开与服务接口鉴权、RLS 和函数权限、输入校验、SSRF、日志泄露及客户端密钥边界。不能仅因使用 Supabase SDK 就认定过滤器安全；也不能以登录检查替代资源授权。

默认只读审核，不执行修复、数据库操作或发布。输出：已确认问题、待验证事项、验证结果、建议；每项包含位置、影响和证据。用户明确授权的修复另按其范围处理。
