## 5. 业务规则：后续修改必须保留

- 奇心现有资料与权限是核心：分组、站点、成员的服务端授权不得因 Agent 或新框架绕过。
- 任务提交／热词雷达按 Tab、日期、筛选条件、页码独立读取当前页，由数据库先筛选、排序、计数；不能先截 2000 条再前端过滤，导致旧词查不到。
- 七日保留窗口包括今天及前六天。“昨日（全部）”表示保留窗口内截至昨天的汇总，不含今天，不是仅昨天一天；“今日（全部）”包含今天。交叉词、共新增词、更新词库等发布资料使用既定昨日口径，其余信号遵守对应发现／采集日期定义。
- 竞品涨排名、连续上涨词优先按资料日期，再按“新增、更新”铭牌，再按其它指标。搜索量上涨也先日期再搜索量；发现上涨日期不能用刷新缓存的日期冒充。
- “覆盖”按精确链接查当前分组全部成员的提交，仍留当前分组。链接不变；覆盖词更新最终词／关键词、日期、操作成员，来源为手动添加、操作类型为覆盖；保留历史并重新匹配搜索量。
- 跌词更新按链接匹配，不能仅凭同名关键词自动认领另一个页面。分发词可指定组员；未指定保持原分组分发。
- 内容发现归档月度概览，归档不随原始明细一起清除。无可查看文字时不应打开空白详情。
- 页面设计系统及旧项目已按负责人要求删除；不要在调研开源项目时恢复它。

细节按需要读取 [覆盖说明](submission-overwrite.md)、[定向分发](distributed-recipients.md)、[上涨日期](keyword-volume-rise-date.md)，不要为小改动无差别加载所有历史文档。
