# 指定组员领取分发词

入口：任务工作台 → 分发词 → 添加分发词 → 领取对象。

- 全组：原有默认行为不变，旧记录不用补写。
- 指定组员：可多选当前分组的有效组员，未选择时不能添加。
- 所选组员共享同一批词，不是给每个人复制一份；原来的认领、冷却和每日名额规则保留。
- 管理员查看全部分发词，并在「领取对象」列查看人选；代组员认领也必须选择名单内的实际领取人。
- 普通组员的接口只返回全组共享及指定给自己的词，不把其他人的词下发到浏览器。
- 改变指定名单或删除分发词，不阻止原先合法认领的任务继续填写、提交；已移除/放弃后重新认领会重新检查当前名单。

保存至 `distributed_keywords.recipient_user_ids`。NULL 代表全组，非空 UUID 数组代表指定名单，空数组不允许。API 与数据库触发器都检查实际领取人，数据库共享锁避免名单调整与认领之间的检查后写入竞态。分发词表保持 service-only，浏览器不能直接读写。

部署只应用 `supabase/migrations/20261015_distributed_recipients.sql`；迁移不更改旧词的名单，不创建真实分发任务。
